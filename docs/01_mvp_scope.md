# MVP Scope

## In Scope
- BLE scan and connect
- Receive audio-like streaming data from LSMP
- Realtime waveform preview
- Start/stop recording
- Save recording as WAV
- Upload WAV to server
- Server-side wheeze analysis
- Show event count result in iPhone app

## Out of Scope
- User login
- Cloud sync
- Background monitoring
- Doctor dashboard
- Real-time AI inference on iPhone
